# শিক্ষকদের সার্ভিস বুক তৈরি করার অ্যাপ

পশ্চিমবঙ্গের শিক্ষকদের সার্ভিস বুকের এন্ট্রি (History of Service, Leave Account, ROPA ফিক্সেশন, ইনক্রিমেন্ট, DA) তৈরি করার অ্যাপ।

- একবার খুলে "Install / হোম স্ক্রিনে যোগ করুন" করলে ইন্টারনেট ছাড়াই চলে।
- সব তথ্য শুধু নিজের ফোন/ল্যাপটপে থাকে। মাঝে মাঝে "ব্যাকআপ ফাইল নামাও" করে রাখুন।
- এখানে নতুন সংস্করণ রাখলে যাঁদের অ্যাপ ইনস্টল করা আছে তাঁদের কাছে নিজে থেকে আপডেট পৌঁছে যায়।

`src/` ফোল্ডারে অ্যাপের মূল কোড আছে।
